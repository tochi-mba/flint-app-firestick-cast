Read this first

Your Fire TV model decides everything

Check the television before you download anything. It takes ten seconds and it decides whether the rest of this page is worth your time.

On the TV: Settings → My Fire TV → About.

What it saysWhat that means
Fire OS 7 or 8 Good. Flint can work with this device.
Vega OS, or no version Stop. Flint cannot work on this device, and no future version will change that.

Vega OS is a Linux system Amazon built in-house. It is not Android, it cannot install apps from outside Amazon's store by any method, and Flint's approach depends on installing a receiver. Devices known to ship with it are the Fire TV Stick 4K Select (October 2025) and the Fire TV Stick HD (2026).

Build it yourself

From source

The same program, compiled by you, with no unrecognised-publisher warning. 

git clone https://github.com/rex-technologies/flint.git
cd flint
./scripts/build.ps1
./scripts/package.ps1

Needs the .NET 10 SDK, Rust with the MSVC toolchain, and Visual Studio Build Tools with the “Desktop development with C++” workload.

Installation

Four steps

  1. Extract the zip

    Right-click, Extract All, and pick somewhere you can find again. C:\Program Files is neither required nor recommended — Flint does not need it.

  2. Run Flint.App.exe

    There is no installer. Flint writes nothing outside its own folder except one marker file under %LOCALAPPDATA%\REX Technologies\Flint recording that you have seen the introduction. To uninstall, delete the folder.

  3. Get past the Windows warning

    Windows will say “Windows protected your PC”. Click More info, then Run anyway. This happens because the build is not code-signed, and the warning is Windows telling you the truth: it does not recognise this publisher. Building from source avoids it entirely.

  4. Turn on ADB debugging

    On the TV: Settings → My Fire TV → Developer Options → ADB debugging. If Developer Options is missing, open About and press Select seven times on the device name. Accept the prompt the TV shows — Flint identifies itself as flint-rex-technologies.

If nothing is found

Some networks stop devices seeing each other. Guest networks, most corporate networks, and access points with client isolation all block the broadcast Flint listens for.

  • Check that the PC and the TV are on the same Wi-Fi network, and that it is not a guest network.
  • Get the TV's address from Settings → My Fire TV → About → Network and type it into the direct address field on the Cast page.
  • Run flint.exe --services from the Flint folder. If it lists nothing at all, the network is the cause rather than the television.

How it is built

Two halves, opposite requirements

Rust

The frame path

Capture, colour convert, encode, packetize, send. A garbage-collector pause landing inside a 16.6 ms frame budget is a stutter you can see, and this side has no collector to pause.

C# and Avalonia

The shell

Discovery, pairing, installation, diagnostics and the interface. Never in the frame path, so it lives where the tooling and the tests are better.

Kotlin

The receiver

Low-latency decode on the television, installed over ADB with the RSA prompt honoured. Not written yet.

The television is usually the bottleneck

A TV's own picture processing commonly adds more delay than an entire casting pipeline. Turning on Game Mode has a larger effect on what you feel than any host-side tuning. Flint measures glass to glass and will not publish a figure that quietly excludes the panel.

Privacy

Nothing leaves your network

  • No account, no cloud relay, no analytics, no crash reporting.
  • Network activity is local discovery and local session traffic only.
  • Flint reads from your TV to identify it, and never installs or changes anything without telling you first.
  • Session tokens authorise a receiver; they do not encrypt anything. Nothing here describes local traffic as private or encrypted, because it is not yet.
